# NBC Repo

This repository contains a simple stock scanner GUI built with Python and Tkinter.

## Requirements

- Python 3.12 or compatible
- [yfinance](https://pypi.org/project/yfinance/)

Install dependencies using pip:

```bash
pip install yfinance
```

## Usage

Run the GUI application with:

```bash
python3 stock_scanner_gui.py
```

Enter a stock ticker symbol (e.g. `AAPL`) and click **Scan** to fetch the latest trading data.
